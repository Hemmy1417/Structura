# Demonstration images

STRUCTURA's demonstration project and live proofs use public photographs. They are credited
here and wherever the app shows them, and every project built from them is labelled as a
demonstration. None of them shows a site belonging to anyone who uses this app.

Each file was resized to at most 800 pixels and re-encoded as a JFIF JPEG, the format GenVM's
model gateway accepts (see [docs/PROBE-REPORT.md](../docs/PROBE-REPORT.md)). That is the only
change made.
